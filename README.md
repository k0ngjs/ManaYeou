서버 주소를 자동으로 찾아 접속하고, Cloudflare 인증까지 앱 안에서 처리할 수 있는 Android 만화 뷰어입니다.
읽던 만화를 북마크에 저장하고, 다음에 앱을 열면 마지막으로 본 페이지부터 이어서 읽을 수 있습니다.

## Features

- 서버 주소를 자동으로 가져와 바로 접속 (수동 입력도 지원)
- 앱 안에서 Cloudflare 인증 처리
- 스크롤 / 페이지 두 가지 읽기 모드 지원
- 페이지 방향 설정 (좌→우 / 우→좌) 및 2페이지 보기
- 읽던 페이지를 기억해 다음에 이어서 읽기
- 북마크 및 최근 본 만화 목록 관리
- 데이터 백업 · 가져오기 (`.yeou`, TSV 형식 지원)
- 라이트 / 다크 / 시스템 테마
